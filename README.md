# UnlockIt

一款面向 Chromium 浏览器的复制粘贴解锁扩展，支持网页文本选择、强制复制粘贴和模拟人工输入。

## ✨ 核心功能

### 📝 解除复制限制
- 在页面主执行环境中优先处理复制、选区和右键菜单事件
- 支持普通 DOM、Shadow DOM 和 iframe 内的文本选择
- 处理常见 CSS `user-select: none` 限制

### 📋 解除粘贴限制
- 绕过常见网页粘贴事件限制
- 支持各类富文本编辑器
- 可通过右键菜单将剪贴板内容写入当前输入区域

### ⌨️ 模拟人工输入
- **快捷键**：`Ctrl+Shift+M` 呼出浮动输入框
- **双击输入**：双击输入框快速呼出
- **速度调节**：支持慢速/正常/快速三档
- **暂停/继续**：输入过程中可随时暂停
- **进度显示**：实时显示输入进度
- 模拟真实打字效果，绕过输入限制

### 🖱️ 右键菜单
- 选中文本 → 「🔓 强制复制选中内容」
- 右键输入框 → 「🔓 强制粘贴」
- 任意位置 → 「🔌 切换插件开关」

### ⚙️ 独立功能开关
- 复制、粘贴和模拟输入可分别启用或关闭
- 设置在弹窗、快捷键、右键菜单和所有标签页之间自动同步
- 关闭插件或子功能后，扩展会恢复本轮修改的页面样式和属性

## 📖 使用方法

### 基础使用

1. **打开控制面板** - 点击浏览器工具栏的插件图标
2. **开启总开关** - 点击「总开关」启用插件
3. **选择功能** - 根据需要开启复制、粘贴、输入功能

### 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+M` | 切换插件开关 |
| `Ctrl+Shift+M` | 打开浮动输入框 |
| `Ctrl+C` | 复制选中内容 |
| `Ctrl+V` | 粘贴内容 |

### 模拟输入

1. 点击目标输入框（或选中）
2. 按 `Ctrl+Shift+M` 呼出浮动输入框
3. 在输入框中粘贴或输入内容
4. 选择输入速度（慢速/正常/快速）
5. 点击「开始输入」按钮 或 按 `Enter` 键
6. 插件将模拟人工打字输入内容
7. 输入过程中可随时暂停或停止


### 安全与隐私

- 插件默认关闭，不影响正常浏览
- 所有操作仅在用户主动开启后生效
- 关闭功能时会恢复扩展写入的页面样式和属性
- 不收集任何用户数据
- 开源透明，可审计代码


## 🐛 常见问题

**Q: 插件在某些网站不生效？**
A: 请确保插件已开启，并尝试刷新页面。部分网站可能需要特定的处理方式，欢迎反馈。

**Q: 如何恢复默认设置？**
A: 当前可手动将总开关关闭并重新选择各子功能；如需清空所有扩展存储，可在浏览器扩展管理页面移除后重新安装。

**Q: 是否支持 Firefox？**
A: 当前版本针对 Chromium 内核浏览器（Chrome、Edge 等）和 Manifest V3 开发，尚未提供 Firefox 兼容版本。

**Q: 浮动输入框无法输入？**
A: 请确保目标输入框已获得焦点（点击一下输入框），然后再按快捷键呼出浮动输入框。
